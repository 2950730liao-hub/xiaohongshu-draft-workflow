# 恢复与重复执行

- 文案已完成而渲染失败时，`resume --id ID` 继续渲染，保留已完成模型结果。
- 模型超时或进程在模型调用中中断时，状态为 `model-unknown`。先核查供应商用量，再决定 `resume --id ID --retry-model`。额外调用仍受任务内 `profile.maxModelCalls` 约束，需要增加时在本机任务 JSON 中明确修改预算。
- 暂存后的回读失败时，状态为 `draft-unknown`。执行 `reconcile --id ID --account '账号名' --browser-profile '配置标签'`。对账只读，找不到草稿时保留未知状态，避免重复新建。
- 已有同标题或正文草稿但缺少本机交接清单时，先在 Chrome 核对。当前版本会阻止直接接管此类草稿。
- 同一任务或浏览器写入被锁定时，先查看 `.data/locks/` 中 PID，确认原进程已经退出后才移除对应锁文件。进程运行中保留锁。
- 图卡内容被修改、账号或浏览器标签变化时，停止复用原交接记录。需要新内容时创建新任务，原草稿保留供用户核对。
- 浏览器配置标签是用户提供的识别标签，实际会话由 OpenCLI 扩展控制。标签本身不会切换 Chrome 配置。
- 模型错误、平台错误与费用信息保留在本机。向外分享前检查来源、签名 URL、客户资料和账号信息。
